# Security Policy

Misclassification bugs in the certified path are correctness incidents for this repository.

Until a fuller disclosure process is published, report issues with:

- a minimal reproducer
- the Lean version
- the command or test path used
- the observed output
- the expected conservative behavior

If an issue could materially mislead downstream certification or audit users, do not rely on public issue text alone. Open a private security advisory when GitHub configuration is available.
